# Regression data

| Directory | Included data |
|---|---|
| `pmlb/samples/` | 243 fixed numeric CSV.gz inputs, with up to 300 rows per task |
| `openml/raw/` | 15 cleaned complete numeric CSV.gz tables, before row sampling and standardization |

Every table has a `target` column. All default training inputs are included; no remote account is needed. `examples/demo.csv` is a generated tutorial table, regenerated by `python examples/make_demo.py`.

PMLB inputs are selected from complete numeric source rows using the dataset-name seed documented in [the dataset workflow](../docs/benchmarks.md). The full upstream source tables are optional and linked in [DOWNLOADS.md](pmlb/DOWNLOADS.md). They are larger than the samples consumed by these examples. [manifest.json](pmlb/manifest.json) records source sizes and sample hashes.

OpenML tables remove declared target-derived columns, columns with more than 1% missing values, and remaining incomplete rows. [catalogue.csv](openml/catalogue.csv) gives targets and exclusions; [sources.json](openml/sources.json) records identifiers, download URLs and licences, and `openml/metadata/` retains upstream metadata. Feature screening and standardization are fitted later, using discovery rows only.

Verify the bundled files using `python verify_data.py`. To rebuild inputs:

```sh
python prepare_data.py --track pmlb --datasets feynman_I_6_2a --download-missing --output rebuilt_data
python prepare_data.py --track openml --datasets yacht_hydrodynamics --from-source --output rebuilt_data
```

Omit `--datasets` to process a whole collection. The script writes new files under the chosen directory and compares the numeric tables with the bundled inputs. It never replaces bundled data. Download caches and regenerated files are excluded from Git. A source serialization can have a different compressed hash while containing identical numeric values; the processing report records both checks.

To use a rebuilt input with the general CSV interface:

```sh
python -m eidos fit --input rebuilt_data/pmlb/samples/feynman_I_6_2a.csv.gz --target target --output results/rebuilt_example
```

Data licences are independent of software terms. See `pmlb/UPSTREAM_LICENSE.txt` and the licence fields in `openml/sources.json`.
